# AWS Architecture Icons

Official icons from the AWS Architecture Icons package, release 07/31/2026
(`Icon-package_07312026`), downloaded 2026-10-28 from https://aws.amazon.com/architecture/icons/.

AWS terms on that page: "We allow customers and partners to use these toolkits and assets to create
architecture diagrams" and to "put icons in materials like whitepapers, presentations, data sheets,
and posters."

Rules for this site:
- Use them only in architecture/flow diagrams and to label AWS services in course material.
- Do not recolor, crop, rotate, distort or restyle the icons; scale proportionally only.
- Do not use them as the AI Workboard logo or brand mark.
- Keep the footer trademark notice: AWS and Amazon Bedrock are trademarks of Amazon.com, Inc. or its
  affiliates; AI Workboard is not affiliated with or endorsed by AWS.

Folders: `service/` (64 px service icons), `resource/` (48 px resource and general icons),
`group/` (32 px group frame icons: AWS Cloud, Region, Account).
